
Data Ingestion, Cleaning & Preprocessing with Pandas
Take a messy, real-world business dataset (10,000+ rows) containing missing values, duplicate records, and inconsistent data types, and clean it thoroughly.


Implementation steps
Load raw dataset (e.g. Retail Sales, Healthcare, or E-Commerce transactions) into Pandas.
Identify and impute/handle missing values, outliers, and incorrect data types.
Perform feature engineering (extract month/year from dates, calculate profit margins).
Export the clean, standardized dataset as clean_dataset.csv.
